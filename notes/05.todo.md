#### Q-004: 自我进化功能的安全边界在哪里？

**背景**: EVO-001~005 涉及代码访问和修改，存在安全风险。

**考虑因素**:
- 哪些文件可以修改？
- 是否需要用户确认？
- 如何回滚错误的修改？

**待决策**。

#### Q-005: 是否需要 Agent 之间的协作机制？

**背景**: 当前设计是单一 Agent，但未来可能需要多 Agent 协作。

**考虑因素**:
- 同一机器上的多个 Agent？
- 跨机器的 Agent 通信？
- 与架构定位是否冲突？

**待决策**。

#### Q-006: 插件市场是否需要？

**背景**: 插件由第三方独立开发和维护，是否需要官方市场？

**考虑因素**:
- 集中式市场的维护成本
- 是否只需提供索引/目录？
- 版本管理和安全审核

**待决策**。

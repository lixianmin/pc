## M2-004: 初始化向导

**优先级**: P0 | **需求**: INIT-001 ~ INIT-008

### 实现步骤

1. 检测 ~/.pc/config.yml 是否存在
2. 如不存在，启动交互式向导
3. 询问 Agent 名字（默认：PersonalClaw）
4. 询问职业（可选，默认：通用助手）
5. 询问性格特征（可选，默认：友好、专业）
6. 询问 Workspace 路径（默认：~/workspace）
7. 创建 ~/.pc/plugins/ 目录
8. 生成两个示例插件（openai-llm 和 telegram-bot）
9. 生成 config.yml 并保存
10. 编写表格驱动测试

### 验收标准

- [x] 首次启动正确进入向导
- [x] 配置正确生成
- [x] 示例插件正确创建
- [x] 单元测试通过

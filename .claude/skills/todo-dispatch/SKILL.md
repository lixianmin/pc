# Todo Dispatch

## 触发条件

用户说"整理 todo.md"、"处理 todo"或类似指令。

## 工作流

```
读取 docs/03.todo.md
       │
       ▼
┌─────────────────────────┐
│  调用 writing-plans     │
│  规划所有待办项          │
└─────────────────────────┘
       │
       ▼
┌─────────────────────────┐
│  生成可执行任务清单      │
│  放入 docs/superpowers/ │
└─────────────────────────┘
       │
       ▼
     清空 todo.md
```

## 执行步骤

### 1. 读取 todo.md

读取 `docs/03.todo.md` 获取所有待办项。

### 2. 规划任务

调用 `writing-plans` skill，将所有待办项规划成：
- 明确的任务边界
- 可执行的步骤
- 验收标准

### 3. 输出任务清单

将规划好的任务写入 `docs/superpowers/plans/`。

### 4. 清空 todo.md

```markdown
# 临时想法收集器

```

## 原则

- **不直接执行**：只做规划，不做执行
- **统一规划**：所有待办项一起规划，确保任务边界清晰
- **可跟踪**：生成的任务清单有明确的状态和进度

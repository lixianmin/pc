# Todo Dispatch

## 工作流

```
读取 docs/03.todo.md
       │
       ▼
┌─────────────────────────┐
│  调用 writing-plans     │
│  规划所有待办项          │
└─────────────────────────┘
       │
       ▼
┌─────────────────────────┐
│  生成可执行任务清单      │
│  放入 docs/superpowers/ │
└─────────────────────────┘
       │
       ▼
     清空 todo.md
```

## 原则

- **不直接执行**：只做规划，不做执行
- **统一规划**：所有待办项一起规划，确保任务边界清晰
- **可跟踪**：生成的任务清单有明确的状态和进度

# 开发经验教训

记录开发过程中遇到的具体错误，避免重复。

---

## 技术错误

### 1. JSON vs YAML 混淆
- **错误**：写了 `plugin.json` 而不是 `plugin.yml`
- **教训**：项目配置统一使用 YAML

### 2. 未使用的导入
- **错误**：重构后留下未使用的导入
- **教训**：每次修改后清理

### 3. 接口类型错误
- **错误**：`cmd *execCmd` 应该是 `cmd execCmd`
- **教训**：理解 Go 接口类型

### 4. slice 比较
- **错误**：直接比较 `[]string`
- **解决**：用 `reflect.DeepEqual`

### 5. expandPath 不完整
- **错误**：没处理单纯 `~` 的情况
- **教训**：边界条件要全面

### 6. MarshalYAML 无限递归
- **错误**：`return c, nil` 导致递归
- **教训**：正确实现 `yaml.Marshaler`

### 7. 管道关闭问题
- **错误**：两次 `Close()` 关闭管道
- **解决**：只由协议 Close() 负责关闭

### 8. goroutine 错误处理
- **错误**：管道关闭后仍尝试读取
- **解决**：忽略 "closed pipe" 错误

### 9. Logger 空指针
- **错误**：测试中 `logger.Get().Info()` 空指针
- **解决**：`if l := logger.Get(); l != nil { ... }`

### 10. 过度封装
- **错误**：为 `logo` 创建复杂 wrapper
- **教训**：成熟库直接使用

---

## 架构问题

### 11. 代码与主流程脱节
- **问题**：功能"完成"但只在测试中使用
- **教训**：验收标准必须包含"主流程中可工作"

### 12. 无用抽象
- **问题**：创建只有一个实现的接口
- **教训**：遵循 "Less is More"

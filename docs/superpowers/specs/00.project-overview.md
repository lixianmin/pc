# PersonalClaw 项目总览

## 项目定位

PersonalClaw（PC）是一个开源的 AI Agent 操作系统内核。

**类比 Linux 内核**：

| 层级 | Linux | PersonalClaw |
|-----|-------|--------------|
| 内核层 | Linux 内核 | PC 核心（Agent 管理、插件系统、通信协议） |
| 内核模块 | 驱动程序 | 内置工具（bash、read、write 等） |
| 用户空间 | 应用程序 | Channel 插件（Telegram、飞书等） |

## 核心原则

1. **核心零依赖** - 核心不包含任何第三方 SDK
2. **插件独立演化** - 插件是独立项目，独立维护
3. **最大化利用三方工具** - 不重复实现已有能力

## 当前架构

```
┌─────────────────────────────────────────────────────────┐
│                      Gateway Daemon                      │
│  (Unix Socket RPC Server, 管理生命周期和状态)             │
└───────────────────────────┬─────────────────────────────┘
                            │ RPC
          ┌─────────────────┼─────────────────┐
          │                 │                 │
          ▼                 ▼                 ▼
    ┌──────────┐      ┌──────────┐      ┌───────────┐
    │  pc tui   │      │ Telegram │      │ 其他插件   │
    │ (内置)    │      │ (独立进程)│      │ (独立进程) │
    └──────────┘      └──────────┘      └───────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                      PC 核心                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐              │
│  │  Engine  │  │  Agent   │  │  Memory  │              │
│  │ (ReAct)  │  │ Manager  │  │ Service  │              │
│  └────┬─────┘  └──────────┘  └──────────┘              │
│       │                                                │
│       ▼                                                │
│  ┌──────────────────────────────────────┐             │
│  │ BAML (LLM 调用) + builtin (工具执行)  │             │
│  └──────────────────────────────────────┘             │
└─────────────────────────────────────────────────────────┘
```

**关键决策**：
- LLM 调用通过 BAML 内置到主进程
- 工具执行通过 `internal/engine/builtin/` 内置
- 仅 Channel 插件保持独立进程
